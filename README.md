# 大声说 · LoudSpeak

给七年级女儿做的**安卓离线**语音表达训练 App。目标：让她在讲数学题时**看见自己说的话**，逐步减少指代词（这个 / 那个 / 它）、把话说完整。

**完全离线**：音频、视频、文字都不出手机，不上传任何服务器。

## 界面样张怎么看

用浏览器打开 `prototype/样张-v6-界面.html`。**必须走 localhost 或直接用文件打开**；要看到真实分贝和波形需授权麦克风（拒绝也能看排布，分贝会走模拟值）。

- 底部控制条：**四档切换** / **行高：建议 ↔ 均分180** / 红晕预览
- 点「开始」录一段，看波形滚动、逐句出字、代词标红、`?` 标不清
- 点「停止」进回放：**波形条可左右拖动定位**，文字随播放高亮，右上出「跳过，看结果 →」
- 长按「停止」2 秒 = 情绪退出（跳过回放与判定）

### 样张里刻意做了两处与文档不同的地方，供对比

1. **行高**：文档写「四行均分 180px」，但 180px 的文字区只装得下 2 行多。样张默认用**建议分配 132 / 128 / 316 / 144**，底部按钮可切回均分对比。
2. **②④ 档占满宽度后单行会到 60 字**，读起来累。样张里左右内收 + 文字区限宽 1180px。

## 关键设计约束（改之前先看）

- **机型**：OPPO A3x 5G（CPH2681）— 天玑 6300 / **无 NPU** / **6GB** / 1604×720 / Android 14
- **采集**：1280×720 横屏 → 裁中间 **544×720**（16 对齐）
- **分栏**：左 3:4 竖幅 544×720 + 右约 1050
- **四档模式**：① 完整录制 ② 仅音频 ③ 纯显示·带画面 ④ 纯显示·音频。区别只在「录不录、保不保存」，四档都有文字 / 波形 / 分贝 / 判定 / 红晕
- **模型**：SenseVoice int8（约 230MB）**必装**；Qwen3-0.6B 为**可选开关、默认关闭、按需加载判完释放**
- **不做**：家长端、五步提示卡、星星/任何奖励与评分、TTS、判定纠正、云端同步
- **保留的评价**：整句评价（问题卡 + 追问语）+ 代词评价（标红 + 计数），**都直接给孩子看**

> 因为判定**直接给孩子看且不可撤销**，所有阈值必须**宁漏勿错**——这是全篇最重要的一条。
