# 大声说 · LoudSpeak

给七年级女儿做的**安卓离线**语音表达训练 App。目标：让她在讲数学题时**看见自己说的话**，逐步减少指代词（这个 / 那个 / 它）、把话说完整。

**完全离线**：音频、视频、文字都不出手机，不上传任何服务器。

## 装 APK（两种方式）

1. **Release 直链（推荐）**：仓库 → **Releases** → `debug-latest` → 下载 `app-debug.apk`。免登录。
2. Actions → 本次运行 → Artifacts → `loudspeak-debug-apk`（需登录 GitHub）。

手机直接安装（仅自用侧载，允许未知来源即可）。

## 模型放哪（必装，约 233MB）

| 文件 | 说明 |
|---|---|
| `asr/model.int8.onnx` | SenseVoice 中文 int8（约 230MB） |
| `asr/tokens.txt` | 词表 |

下载来源见 `docs/模型下载说明.md`（hf-mirror 实测可达）。拿到文件后三种方式：

1. **扫描（推荐）**：设置 → 「扫描模型」→ 自动在 App 私有目录 / `Download/SpeakClear` 等常见位置找模型 → 选中即导入。
2. **电脑 USB 直拷**：把整个模型文件夹拷到 `Android/data/com.oska.loudspeak/files/models/asr/`。
3. **SAF 选目录**：设置 → 「从文件管理器选择模型目录」。

导入后点「校验模型」确认加载成功（eMMC 首次约 15–30 秒）。

## 崩溃与错误报告（调试用）

App 内置错误报告：全局崩溃 + 运行期错误（ASR/相机失败等）自动落盘到 `error_reports/`（保留最近 20 份，完全离线）。查看入口：**设置 → 错误报告**，可逐条看详情、清空。调试时把报告内容贴回来即可。

## 真机验证轮（按 `计划-v6-AI执行批次.md`）

- **B1**：主界面 → 系统自检 → 采集验证 → 录 30 秒 → 看「实测分辨率」是否 544×720（或其它 3:4 值）
- **B2**：录 3 分钟 → 反馈出字延迟 / 断句是否合理 / 内存
- **B3**：四档各跑一遍，③④ 档跑 20 分钟（确认零落盘 + 内存稳定）
- **B4**：录 30 句讲题 → 统计 F1（工具后补）

每轮只要 2–4 个数字，贴回来即可。

## 关键设计约束（改之前先看）

- **机型**：OPPO A3x 5G（CPH2681）— 天玑 6300 / **无 NPU** / **6GB** / 1604×720 / Android 14
- **采集**：1280×720 横屏 → 裁中间 **544×720**（16 对齐）；ViewPort 保证预览与录制同视场
- **四档模式**：① 完整录制 ② 仅音频 ③ 纯显示·带画面 ④ 纯显示·音频。区别只在「录不录、保不保存」，四档都有文字 / 波形 / 分贝 / 判定 / 红晕；**③④ 档一个字节都不写**
- **不做**：家长端、五步提示卡、星星/任何奖励与评分、TTS、判定纠正、云端同步
- **保留的评价**：整句评价（问题卡 + 追问语）+ 代词评价（标红 + 计数），**都直接给孩子看**
- 阈值**宁漏勿错**——这是全篇最重要的一条（判定直接给孩子看且不可撤销）

## 工程结构

| 路径 | 内容 |
|---|---|
| `app/` | Android 工程（Kotlin + CameraX + sherpa-onnx 1.13.8 AAR） |
| `app/libs/` | sherpa-onnx 官方预编译 AAR（SenseVoice 离线识别） |
| `app/src/main/java/com/oska/loudspeak/core/` | 采集 / 分贝 / VAD / ASR / 规则引擎 / 会话存储 |
| `.github/workflows/build.yml` | push 到 main 自动编译；失败把错误写进运行摘要；成功发 `debug-latest` Release |
| `pc/` | PC 侧脚本（模型下载 / 校验 / PC-1 准备） |
| `docs/` | 设计文案 v6（权威）、评审意见、模型下载说明 |
| `prototype/` | 界面样张 / 旧原型 |
